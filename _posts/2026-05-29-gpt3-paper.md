`Language Models are Few-Shot Learners`는 GPT-3를 소개한 논문이다. 핵심 메시지는 모델 크기와 데이터, 학습 규모를 키우면 별도의 fine-tuning 없이도 prompt 안의 예시만 보고 새로운 task를 수행할 수 있다는 것이다.

## 기존 방식의 문제

기존 NLP 모델은 보통 task별 fine-tuning을 했다. 감성 분석, 번역, 질의응답 같은 task마다 labeled dataset을 준비하고 모델을 추가 학습시켜야 했다.

이 방식은 성능은 좋지만 비용이 크다. 새로운 task가 생길 때마다 데이터를 모으고, 학습하고, 평가해야 한다. GPT-3 논문은 이 과정을 줄이고, 사람이 문제를 푸는 방식처럼 예시 몇 개만 보고 task를 수행할 수 있는지를 실험했다.

## Zero-shot, One-shot, Few-shot

논문은 evaluation setting을 세 가지로 나눈다.

- Zero-shot: task 설명만 주고 바로 답하게 한다.
- One-shot: 예시 하나를 prompt에 넣고 답하게 한다.
- Few-shot: 여러 예시를 prompt에 넣고 패턴을 따라 답하게 한다.

중요한 점은 이 과정에서 모델 weight는 업데이트하지 않는다는 것이다. 모든 적응은 context 안에서 일어난다. 그래서 이를 in-context learning이라고 부른다.

## 모델 규모

GPT-3는 GPT-2 계열의 autoregressive Transformer 구조를 확장했다. 가장 큰 모델은 175B parameter 규모였고, 여러 크기의 모델을 함께 실험해 scale이 성능에 미치는 영향을 비교했다.

논문에서 반복적으로 보이는 패턴은 모델이 커질수록 few-shot 성능이 좋아진다는 점이다. 작은 모델은 prompt 예시를 잘 활용하지 못하지만, 큰 모델은 예시에서 task 형식을 더 잘 읽어낸다.

이 결과가 중요한 이유는 단순히 parameter 수가 커졌다는 데 있지 않다. 모델이 커질수록 pretraining에서 본 다양한 패턴을 context 안에서 조합하는 능력이 좋아진다는 점을 보여줬다. 즉, LLM은 task별 classifier라기보다 자연어로 지시하고 예시를 넣어 사용할 수 있는 범용 인터페이스에 가까워졌다.

## 학습 방식

GPT-3는 autoregressive language modeling으로 학습된다. 이전 token들을 보고 다음 token을 예측하는 objective다.

$$
P(x) = \prod_{t=1}^{n} P(x_t | x_1, ..., x_{t-1})
$$

이 방식은 단순하지만 매우 범용적이다. 번역, 요약, 질의응답, 문장 완성 모두 결국 주어진 context 다음에 올 token을 예측하는 문제로 바꿀 수 있기 때문이다.

GPT-3는 별도의 task-specific fine-tuning 없이 다양한 benchmark에서 평가됐다. 이는 모델이 pretraining만으로도 여러 task 형식을 어느 정도 흡수했는지 보려는 실험 설계다.

## Few-shot 성능의 의미

Few-shot learning은 단순히 prompt engineering 기법이 아니다. 모델이 pretraining 중 학습한 언어적 패턴과 지식을 context에서 재조합할 수 있음을 보여준다.

예를 들어 prompt에 영어-프랑스어 번역 예시를 몇 개 넣으면, 모델은 추가 학습 없이 다음 문장도 같은 형식으로 번역하려고 한다. 질문-답변 예시를 넣으면 다음 질문에 답하는 형식도 따라간다.

Prompt는 모델에게 주는 임시 데이터셋처럼 동작한다. Few-shot prompt에 입력-출력 예시를 넣으면 모델은 그 패턴을 이어서 다음 답을 생성한다. 이때 모델이 실제로 weight를 업데이트하는 것은 아니므로, context window를 벗어나면 그 예시는 사라진다.

그래서 in-context learning은 fine-tuning과 다르다. Fine-tuning은 모델 parameter 자체를 바꾸고, in-context learning은 입력 context만 바꾼다. 빠르게 실험하고 task를 바꾸기에는 in-context learning이 유리하지만, 안정적인 형식과 성능이 필요하면 fine-tuning이나 instruction tuning이 필요할 수 있다.

## 논문이 남긴 변화

GPT-3 이후 LLM을 쓰는 방식은 크게 바뀌었다. 모델을 task별로 작게 학습시키는 것보다, 큰 범용 모델에 자연어 instruction과 예시를 넣어 문제를 푸는 방식이 널리 퍼졌다.

이 흐름은 이후 instruction tuning과 RLHF로 이어졌다. GPT-3는 prompt만으로 가능성을 보여줬고, instruction tuning은 사람이 원하는 지시 형식에 더 잘 맞게 모델을 조정했다. RLHF는 답변의 유용성, 안전성, 선호도를 보상으로 반영했다.

또한 retrieval, tool use, agent 구조도 GPT-3식 interface 위에서 발전했다. 모델이 모든 지식을 parameter 안에 담는 대신, 검색 결과나 도구 호출 결과를 context로 넣고 답하게 만드는 방식이다.

## 한계

GPT-3가 모든 문제를 해결한 것은 아니다. 논문에서도 몇 가지 한계를 언급한다.

- reasoning이 필요한 문제에서는 여전히 불안정하다.
- 긴 문맥에서 일관성을 유지하는 데 한계가 있다.
- 학습 데이터에 포함된 bias를 그대로 반영할 수 있다.
- 모델 규모가 커지면서 계산 비용과 배포 비용이 매우 커진다.

또한 few-shot 성능이 좋다는 것은 task를 완전히 이해했다는 뜻은 아니다. prompt 형식에 민감하고, 같은 문제도 표현을 바꾸면 결과가 달라질 수 있다.

또 하나의 한계는 평가 contamination 가능성이다. 큰 웹 데이터로 학습한 모델은 benchmark와 유사한 데이터를 학습 중 봤을 수 있다. 논문에서도 이런 문제를 줄이려 했지만, 대규모 웹 학습에서는 완전히 배제하기 어렵다.

그리고 모델이 그럴듯한 문장을 생성한다고 해서 항상 사실을 말하는 것은 아니다. GPT-3 이후 hallucination 문제가 중요한 연구 주제가 된 이유도 여기에 있다.

## 정리

GPT-3 논문의 핵심은 scale이 in-context learning 능력을 크게 끌어올린다는 것이다. task별 fine-tuning 대신 prompt 안의 설명과 예시만으로 다양한 문제를 풀 수 있음을 보여줬고, 이후 LLM 활용 방식의 중심을 prompt와 context 설계로 이동시켰다.

현재의 instruction tuning, RLHF, tool use, agent 구조도 이 흐름 위에 있다. GPT-3는 LLM이 단순 language model을 넘어 범용 task interface로 쓰일 수 있다는 가능성을 강하게 보여준 논문이다.
