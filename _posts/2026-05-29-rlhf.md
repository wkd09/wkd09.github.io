RLHF는 **Reinforcement Learning from Human Feedback**의 약자다.

한마디로 정리하면, 사람이 직접 보상 함수를 수식으로 정의하는 대신 **인간의 선호를 학습한 reward model을 만들고, 그 reward model을 기준으로 LLM을 강화학습시키는 방법**이다.

LLM은 기본적으로 next-token prediction으로 학습한다. 하지만 다음 토큰을 잘 맞히는 것만으로는 답변의 유용성, 안전성, 자연스러움, 사용자의 의도 반영 같은 기준을 충분히 학습하기 어렵다.

RLHF는 이 문제를 인간의 평가 기준을 보상 함수에 가깝게 근사하는 방식으로 해결한다.

## 왜 필요한가

대규모 언어 모델은 사전학습만으로도 뛰어난 언어 능력을 갖는다. 하지만 실제 대화형 서비스에 사용하려면 다음 문제가 남는다.

- 맞는 말처럼 보이지만 사용자의 질문과 어긋난 답변
- 톤, 길이, 안전성 제어의 어려움
- "좋은 답변"을 명확한 수식으로 정의하기 어려움
- 편향, 유해성, 부정확한 자신감

결국 좋은 답변인지 아닌지는 사람이 판단할 수 있지만, 그 판단 기준을 직접 loss function으로 만들기는 어렵다. RLHF는 사람의 선호 데이터를 학습해 이 기준을 모델이 사용할 수 있는 보상으로 바꾼다.

## 핵심 흐름

RLHF의 흐름은 다음처럼 볼 수 있다.

```text
Human Preference -> Reward Model -> Reinforcement Learning
```

사람이 모든 답변에 직접 점수를 매기는 것이 아니다. 여러 응답 중 어떤 것이 더 나은지 비교한 데이터를 만들고, 그 비교 데이터를 reward model이 학습한다.

이후 LLM은 reward model이 더 높은 점수를 주는 방향으로 업데이트된다.

## RLHF Pipeline

RLHF는 보통 다음 단계로 진행된다.

## 1. Pretraining

먼저 대규모 텍스트 데이터로 next-token prediction을 학습한다.

이 단계의 목표는 언어 자체를 이해하고 생성하는 기본 능력을 확보하는 것이다.

## 2. Supervised Fine-Tuning

이후 사람이 작성한 좋은 instruction-response 데이터를 사용해 supervised fine-tuning을 한다.

예시는 다음과 같다.

```json
{
  "instruction": "문장을 긍정적으로 바꿔줘",
  "input": "오늘 날씨가 별로야",
  "output": "오늘 날씨가 흐리지만 나름 분위기가 있어"
}
```

이 단계에서 모델은 사용자의 지시를 따르는 기본 패턴을 배운다.

## 3. Reward Model Training

Reward model은 인간의 선호를 학습한다.

보통 데이터는 pairwise preference 형태다.

```text
(Question, Answer A, Answer B)
Human preference: A가 더 좋다
```

Reward model의 목표는 다음 관계를 만족하도록 학습하는 것이다.

```text
R(Question, Answer A) > R(Question, Answer B)
```

즉, 답변의 절대 점수보다 "어느 답변이 더 나은가"라는 상대 비교를 학습한다.

## 4. Policy Optimization

마지막으로 reward model을 기준으로 언어 모델의 policy를 업데이트한다.

LLM 관점에서 강화학습 요소를 대응시키면 다음과 같다.

| 개념 | LLM에서의 의미 |
| --- | --- |
| State | 현재까지 생성된 텍스트 |
| Action | 다음 토큰 선택 |
| Policy | 다음 토큰 확률 분포 |
| Reward | reward model의 점수 |

모델은 "어떤 텍스트를 생성해야 높은 보상을 받는가"를 학습한다.

## PPO와 Reward Hacking

단순히 reward model 점수를 높이는 방향으로만 학습하면 문제가 생길 수 있다. 모델이 좋은 답변을 만드는 것이 아니라 reward model이 좋아할 만한 패턴만 과하게 학습할 수 있기 때문이다.

이 현상을 reward hacking이라고 한다.

예를 들어 답변이 실제로 유용하지 않은데 특정 표현을 반복하면 reward model 점수가 높게 나오는 경우, 모델은 그 패턴을 악용할 수 있다.

이를 완화하기 위해 PPO 같은 방식에서는 기존 정책에서 너무 멀어지지 않도록 제한을 둔다. KL divergence 기반 제약을 사용해 보상은 올리되, 사전학습과 SFT로 얻은 언어 능력이 무너지지 않게 한다.

## 정리

RLHF는 LLM을 사람의 사용 기준에 맞추기 위한 alignment 방법이다.

핵심은 다음과 같다.

- 인간의 선호 데이터를 수집한다.
- 선호 데이터를 reward model로 학습한다.
- reward model을 기준으로 LLM policy를 업데이트한다.
- PPO와 KL 제약으로 reward hacking과 언어 능력 붕괴를 완화한다.

RLHF를 이해하면 ChatGPT 같은 instruction-following 모델이 단순한 next-token prediction을 넘어 어떻게 사람의 기대에 맞는 답변을 만들도록 조정되는지 볼 수 있다.
