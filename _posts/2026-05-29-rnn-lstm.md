RNN은 Recurrent Neural Network의 약자로 순환 신경망을 의미한다.

RNN은 sequence 데이터를 처리하기 위해 사용된다. sequence는 문장, 시계열 데이터처럼 순서가 중요한 데이터다. RNN은 이전 시점의 hidden state를 다음 시점의 입력으로 넘기면서 정보를 이어간다.

## RNN의 기본 구조

RNN의 핵심은 memory cell이다.

현재 입력과 이전 hidden state를 함께 사용해 현재 hidden state를 만든다. 이 hidden state는 다음 시점으로 전달된다.

즉, RNN은 현재 입력만 보는 것이 아니라 이전까지의 정보를 함께 참고한다.

```text
h_t = f(x_t, h_{t-1})
y_t = g(h_t)
```

여기서 `x_t`는 현재 입력, `h_t`는 현재 hidden state, `y_t`는 현재 출력이다.

## RNN의 입력과 출력 형태

RNN은 입력과 출력 길이를 다르게 설계할 수 있다.

One-to-many는 하나의 입력에서 여러 출력을 만든다. 이미지 하나를 입력받아 문장 caption을 생성하는 image captioning이 예시다.

Many-to-one은 sequence 입력에서 하나의 출력을 만든다. 문장 감정 분류나 스팸 탐지가 예시다.

Many-to-many는 sequence 입력에서 sequence 출력을 만든다. 번역기나 챗봇처럼 입력 문장에 대해 출력 문장을 생성하는 문제가 여기에 해당한다.

## BPTT

RNN 학습에는 Back Propagation Through Time, 즉 BPTT가 사용된다.

BPTT는 RNN을 시간 방향으로 펼친 뒤, 각 시점의 error를 뒤에서 앞으로 전파해 학습하는 방식이다.

RNN에서는 같은 weight가 여러 시점에서 반복 사용된다. 그래서 특정 시점의 loss가 이전 여러 시점의 hidden state와 weight에 영향을 준다.

문제는 sequence가 길어질수록 gradient가 계속 곱해진다는 점이다. 이 과정에서 gradient가 0에 가까워지는 vanishing gradient 문제가 생기기 쉽다.

## RNN의 한계

RNN은 이전 정보를 기억하려고 하지만, 긴 sequence에서는 오래된 정보를 유지하기 어렵다.

예를 들어 문장 앞부분의 정보가 뒤쪽 예측에 중요할 수 있는데, RNN은 시간이 길어질수록 그 정보가 희미해질 수 있다. 이를 장기 의존성 문제라고 한다.

이 문제를 완화하기 위해 LSTM이 등장했다.

## LSTM

LSTM은 Long Short-Term Memory의 약자로, RNN의 gradient 소실 문제와 장기 의존성 문제를 완화하기 위해 고안된 구조다.

LSTM은 cell state를 통해 정보를 오래 유지하고, gate를 통해 어떤 정보를 기억하고 지울지 제어한다.

대표적인 gate는 세 가지다.

- Forget gate
- Input gate
- Output gate

## Forget Gate

Forget gate는 이전 cell state에서 어떤 정보를 지울지 결정한다.

sigmoid 함수를 사용해 0과 1 사이 값을 만든다. 값이 0에 가까우면 정보를 버리고, 1에 가까우면 정보를 유지한다.

## Input Gate

Input gate는 새로운 정보를 cell state에 얼마나 반영할지 결정한다.

sigmoid는 후보 정보를 얼마나 반영할지 결정하고, tanh는 새로 반영할 후보 값을 만든다. 두 값을 조합해 cell state를 업데이트한다.

## Output Gate

Output gate는 cell state를 바탕으로 현재 hidden state를 얼마나 출력할지 결정한다.

cell state에 tanh를 적용한 값과 sigmoid gate 값을 곱해 최종 hidden state를 만든다.

## 정리

RNN은 sequence 데이터를 처리하기 위한 기본 구조다. 하지만 긴 sequence에서 gradient 소실과 장기 의존성 문제가 생긴다.

LSTM은 cell state와 gate 구조를 통해 필요한 정보는 오래 유지하고 불필요한 정보는 지우도록 설계됐다.

Transformer가 등장하기 전까지 RNN과 LSTM은 자연어 처리와 시계열 모델링에서 중요한 기본 구조였다.
