## RNN이란?

RNN은 Recurrent Neural Network의 약자로 순환 신경망을 뜻한다.

RNN은 출력와 입력을 시퀀스 단위로 한다. 시퀀스는 문장으로 된 단위를 뜻한다.

RNN에서 은닉층에서 활성화 함수를 통해 결과를 내보는 역할을 노드 셀.

이전 값을 기억할려고 하는 일종의 메모리 역할을 수행하는 셀을 메모리 셀.

RNN 이름에서 알 수 있듯이, 은닉층의 메모리 셀에서 나온 값이 다음 은닉층 메모리에 입력된다. 이 값을 은닉 상태라고함.

![rnn unrolled diagram](/assets/images/blog/rnn-unrolled.png)

이전 메모리 셀의 출력 값과 현재 입력 값 두개가 입력으로 사용된다. RNN은 입력과 출력의 길이를 다르게 설계할 수 있어 다양한 용도로 사용할 수 있다.

### 일 대 다(one-to-many)

하나의 입력에 대해 여러개의 출력을 가지는 일대다 모델의 경우

하나의 이미지 입력에 대해서 사진의 제목을 출력하는 이미지 캡셔닝에 사용할 수 있습니다.

사진의 제목이 단어들의 나열이므로 시퀀스 출력이다.

![one-to-many rnn example](/assets/images/blog/rnn-unrolled.png)

### 다 대 일(many-to-one)

시퀀스 입력에 대해서 하나의 출력을 하는 다 대 일 모델은

입력 문서가 긍정적인지 부정적인지 분류하는 감정 분류, 스팸 탐지에 사용할수있다.

![many-to-one rnn example](/assets/images/blog/rnn-unrolled.png)

### 다 대 다(many-to-many)

시퀀스 입력에 대해 시퀀스 출력을 하는 다 대 다 모델일 경우 챗봇이나 번역기에 사용

![many-to-many rnn example](/assets/images/blog/rnn-unrolled.png)

RNN 층은 사용자에 설정에 따라 두가지 출력을 내보낸다.

메모리 셀은 최종 시점의 은닉상태에만 리턴 할수있고, 메모리 셀의 각 시점의 은닉 상태들을  모두 리턴할 수 있다. 각 시점의 모든 은닉 상태를 리턴하기 위해선 RNN층의 return_sequence 매개변수를 True로 설정하면 가능하다. 이때 은닉 상태는 출력 값이 아니라 이 은닉 상태가 활성화 함수를 지난 것이 출력 값이다.

![rnn hidden states output](/assets/images/blog/rnn-unrolled.png)

## RNN 학습

학습에선 Back Propagation의 확장인 BPTT가 사용됩니다.

BPTT는 Back Propagation Through Time의 약자로, 재귀적인 형태의 모델을 시간에 대해 펼쳐서 현재 시점의 에러를 최초 시점까지 전파해 학습하는 것

![bptt overview](/assets/images/blog/rnn-bptt.png)

위 그림은 RNN을 나타낸것이다.

U,V,W는 가중치를 뜻하고 x는 현재 시점의 입력 값, s는 은닉층의 메모리 셀의 출력 값, y는 해당 시점의 출력 값.

![rnn equations](/assets/images/blog/rnn-backprop-equations.png)

![rnn equation details](/assets/images/blog/rnn-backprop-equations.png)

위 그림의 E는 각 시점의 error를 뜻함.

첫 번째 식은 각 시점의 error를 나타낸 식이고, 두 번째는 이전 모든 시점의 error를 합친 값 total loss를 나타냄. RNN에서는 이전의 모든 시점에 error를 활용해 학습한다.

t=3 시점에서 BPTT가 이뤄지는 예시를 보겠습니다.

![bptt time-step example](/assets/images/blog/rnn-bptt.png)

![bptt gradient flow](/assets/images/blog/rnn-bptt.png)

가중치(W)가 모든 시점에서 메모리 셀의 출력 값(S)을 구할때 사용 되었기 때문에 위 수식에서 처럼 k=0 부터 3까지 계산하여 합한다. 이렇게 학습 시에 앞 시점의 계속 전파가 일어나는데, 전파가 길어 질수록 기울기 값이 0에 가까워지게 되는 기울기 손실이 발생함.

## LSTM

RNN의 그래디언트 소실 문제를 해결하기 위해 고안된 모델이다. 이전 정보를 오랫동안 기억할 수 있는 메모리 셀이 있고 이를 통해 긴 시퀀스 데이터를 처리할수있다.(장기 의존성 문제 해결)

### LSTM 구조

LSTM의 메모리 셀은 입력값과 이전 상태에 따라 값을 업데이트 하고, 새로운 상태를 출력한다. 그러나 그 차이점은 셀의 값을 얼마나 기억할지 결정하는 것이 가능한 게이트가 있어 필요한 정보만 기억하도록 제어 가능, 메모리 셀 안에는 상태 정보를 변경하는 게이트를 가지고 있다. 입력 게이트, 망각 게이트, 출력 게이트 세가지 게이트와 cell state로 구성되어 있다.

![lstm cell structure](/assets/images/blog/lstm-cell.png)

### 셀 상태

Cell State는 LSTM에서 중요한 개념 중 하나이다. 이전 상태에서 현재 상태까지 유지되는 정보의 흐름을 나태내고, 이를 통해 오래된 정보를 기억하고 새로운 정보를 적절히 갱신할 수 있다. 셀 상단에 Cell State가 있고 Cell State는 자기 자신에게 프드백 된다. Cell State는 망각 게이트와 입력 게이트에서 두번에 변화를 겪고 그 결과가 다음 입력으로 들어가는 값 ct입니다.

### 망각 게이트

망각 게이트는 이전의 셀 상태의 정보를 지울 것인지 말 것인지 결정한다. 망각 게이트에서 만들어지는 신호는 ft이고 이 값을 계산하기 위해 사용되는 활성화 함수는 sigmoid 함수이다. sigmoid는 0~1 사이의 값을 갖는데 값이 0이면 셀 상태 정보도 0이 되어 삭제되고 1이면 그대로 전달됨

![lstm equations](/assets/images/blog/lstm-equations.png)

### 입력 게이트

입력 게이트는 새로운 정보를 어떻게 반영할 것인지에 대한 결정을 내린다. LSTM은 기존의 정보와 새로운 정보를 적절하게 조합해, 더 정확한 예측을 수행할 수 있다. 입력 게이트엔 sigmoid와 tanh 함수가 있다. 두개의 함수를 만드는 이유는 탄젠트 함수는 RNN에서 사용되는 출력 방식과 같고, 시그모이드 함수는 후보 값을 얼마나 전달할지 결정 내리는 값, 이 두 값을 곱해서 셀 상태에 더하면 최종적으로 ct가 결정된다.

### 출력 게이트

출력 게이트는 셀 상태 값에 탄젠트 함수를 적용한 값을 출력으로 사용, 출력이 얼마나 중요한지 조절하기 위해 은닉 상태와 현재 입력에 대해 시그모이드 함수를 적용해 0~1 사이 값으로 만들고 출력하고자는 신호와 곱해 크기 조절 후 출력
