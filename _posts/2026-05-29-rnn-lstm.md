## RNN이란?

RNN은 Recurrent Neural Network의 약자로, 순환 신경망을 뜻한다.

RNN은 입력과 출력을 시퀀스 단위로 다룬다. 시퀀스는 문장처럼 순서가 있는 데이터 단위를 뜻한다.

RNN의 은닉층에서 활성화 함수를 거쳐 결과를 내보내는 기본 단위를 노드 또는 셀이라고 볼 수 있다.

이전 값을 기억하려는 일종의 메모리 역할을 수행하는 셀을 메모리 셀이라고 한다.

RNN이라는 이름에서 알 수 있듯이, 은닉층의 메모리 셀에서 나온 값이 다음 시점의 은닉층 메모리에 입력된다. 이 값을 은닉 상태라고 한다.

![rnn unrolled diagram](/assets/images/blog/rnn-unrolled.png)

이전 메모리 셀의 출력값과 현재 입력값 두 개가 입력으로 사용된다. RNN은 입력과 출력의 길이를 다르게 설계할 수 있어 다양한 용도로 사용할 수 있다.

### 일 대 다(one-to-many)

하나의 입력에 대해 여러 개의 출력을 가지는 일대다 모델의 경우,

하나의 이미지 입력에 대해 사진의 제목을 출력하는 이미지 캡셔닝에 사용할 수 있다.

사진의 제목이 단어들의 나열이므로 시퀀스 출력이다.

### 다 대 일(many-to-one)

시퀀스 입력에 대해서 하나의 출력을 하는 다 대 일 모델은

입력 문서가 긍정적인지 부정적인지 분류하는 감정 분류나 스팸 탐지에 사용할 수 있다.

### 다 대 다(many-to-many)

시퀀스 입력에 대해 시퀀스 출력을 하는 다 대 다 모델은 챗봇이나 번역기에 사용할 수 있다.

RNN 층은 사용자의 설정에 따라 두 가지 출력을 내보낸다.

메모리 셀은 최종 시점의 은닉 상태만 리턴할 수도 있고, 각 시점의 은닉 상태를 모두 리턴할 수도 있다. 각 시점의 모든 은닉 상태를 리턴하려면 RNN 층의 `return_sequences` 매개변수를 `True`로 설정하면 된다. 이때 은닉 상태 자체가 곧 출력값은 아니며, 은닉 상태가 활성화 함수를 지난 값이 출력값이 된다.

## RNN 학습

학습에서는 Backpropagation의 확장인 BPTT가 사용된다.

BPTT는 Backpropagation Through Time의 약자로, 재귀적인 형태의 모델을 시간축으로 펼쳐 현재 시점의 error를 이전 시점까지 전파해 학습하는 방법이다.

![bptt overview](/assets/images/blog/rnn-bptt.png)

위 그림은 RNN을 나타낸 것이다.

$U, V, W$는 가중치를 뜻하고, $x$는 현재 시점의 입력값, $s$는 은닉층 메모리 셀의 출력값, $y$는 해당 시점의 출력값이다.

![rnn equations](/assets/images/blog/rnn-backprop-equations.png)

위 그림의 $E$는 각 시점의 error를 뜻한다.

첫 번째 식은 각 시점의 error를 나타낸 식이고, 두 번째 식은 이전 모든 시점의 error를 합친 total loss를 나타낸다. RNN에서는 이전 모든 시점의 error를 활용해 학습한다.

$t=3$ 시점에서 BPTT가 이뤄지는 예시를 보자.

가중치 $W$가 모든 시점에서 메모리 셀의 출력값 $S$를 구할 때 사용되기 때문에, 위 수식처럼 $k=0$부터 $3$까지 계산하여 합한다. 이렇게 학습 시 앞 시점까지 계속 전파가 일어나는데, 전파가 길어질수록 기울기 값이 0에 가까워지는 기울기 소실 문제가 발생할 수 있다.

## LSTM

LSTM은 RNN의 gradient vanishing 문제를 해결하기 위해 고안된 모델이다. 이전 정보를 오랫동안 기억할 수 있는 메모리 셀이 있고, 이를 통해 긴 시퀀스 데이터를 처리할 수 있다. 즉 장기 의존성 문제를 완화한다.

### LSTM 구조

LSTM의 메모리 셀은 입력값과 이전 상태에 따라 값을 업데이트하고 새로운 상태를 출력한다. RNN과의 중요한 차이점은 셀의 값을 얼마나 기억할지 결정하는 게이트가 있다는 점이다. 메모리 셀 안에는 상태 정보를 변경하는 입력 게이트, 망각 게이트, 출력 게이트와 cell state가 있다.

![lstm cell structure](/assets/images/blog/lstm-cell.png)

### 셀 상태

Cell State는 LSTM에서 중요한 개념 중 하나이다. 이전 상태에서 현재 상태까지 유지되는 정보의 흐름을 나타내고, 이를 통해 오래된 정보를 기억하면서 새로운 정보를 적절히 갱신할 수 있다. Cell State는 망각 게이트와 입력 게이트에서 두 번 변화를 겪고, 그 결과가 다음 시점으로 전달되는 $c_t$가 된다.

### 망각 게이트

망각 게이트는 이전 셀 상태의 정보를 지울 것인지 유지할 것인지 결정한다. 망각 게이트에서 만들어지는 신호는 $f_t$이고, 이 값을 계산하기 위해 sigmoid 함수를 사용한다. sigmoid는 0~1 사이의 값을 갖는데, 값이 0이면 셀 상태 정보가 삭제되고 1이면 그대로 전달된다.

### 입력 게이트

입력 게이트는 새로운 정보를 어떻게 반영할 것인지 결정한다. LSTM은 기존 정보와 새로운 정보를 적절히 조합해 더 정확한 예측을 수행할 수 있다. 입력 게이트에는 sigmoid와 tanh 함수가 사용된다. tanh는 후보 값을 만들고, sigmoid는 그 후보 값을 얼마나 전달할지 결정한다. 이 두 값을 곱해서 셀 상태에 더하면 최종적으로 $c_t$가 결정된다.

### 출력 게이트

출력 게이트는 셀 상태 값에 tanh를 적용한 값을 출력으로 사용한다. 출력이 얼마나 중요한지 조절하기 위해 은닉 상태와 현재 입력에 sigmoid 함수를 적용해 0~1 사이 값으로 만들고, 출력하려는 신호와 곱해 크기를 조절한 뒤 내보낸다.
