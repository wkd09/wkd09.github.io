# 블로그 UX 감사 및 개선 계획

감사일: 2026-08-22  
대상: https://wkd09.github.io/  
점검 흐름: 홈 → 검색 → 글 읽기, 데스크톱 1280×720 및 모바일 390×844

## 결론

콘텐츠의 전문성, 홈의 주제 분류, 글 본문의 구조와 핵심 요약은 강점이다. 가장 먼저 고칠 부분은 모바일에서 본문을 가리는 테마 버튼, 한국어와 영어가 섞인 인터페이스, 검색의 `keyup` 전용 이벤트, 글 진입부의 과도한 세로 공간이다.

## 현재 상태

| 영역 | 상태 | 관찰 |
|---|---|---|
| 홈 | 양호 | 주제 3개가 명확하지만 `최근 글`과 `Latest Notes`가 중복되고 첫 화면에 실제 글 카드가 잘 보이지 않는다. |
| 검색 | 작동하지만 개선 필요 | `cache` 검색에서 5개 결과가 정상 노출된다. 다만 입력 안내와 결과 수가 영어이고, 이벤트가 `keyup`에만 묶여 있어 자동완성·음성입력·일부 모바일 입력에 취약하다. |
| 글 읽기 | 양호 | 제목, 메타정보, 핵심 요약, 본문 계층이 좋다. 데스크톱 목차는 작고 대비가 약하다. |
| 모바일 홈 | 개선 필요 | 한 열 전환은 자연스럽지만 플로팅 테마 버튼이 카드 위를 가린다. |
| 모바일 글 | 개선 필요 | 프로필 영역과 큰 제목 때문에 실제 내용 진입이 늦고 테마 버튼이 본문을 가린다. |

## 우선순위별 실행 계획

### P0 — 사용 방해 요소 제거

1. 테마 전환 버튼을 헤더 유틸리티 영역으로 옮기고 아이콘과 상태 라벨을 제공한다.
   - 모바일 카드·본문과 겹치지 않아야 한다.
   - 44×44px 이상의 터치 영역과 명확한 포커스 표시를 유지한다.
2. 검색 이벤트를 `keyup`에서 `input`으로 바꾼다.
   - 키보드 입력, 붙여넣기, 자동완성, 모바일 음성 입력에서 동일하게 결과가 갱신되어야 한다.
   - 빈 검색어에는 안내 문구, 결과가 없을 때에는 한국어 빈 상태를 보여 준다.

### P1 — 언어와 정보 구조 정리

3. 인터페이스 문구를 한국어로 통일한다.
   - `Latest Notes` → `최근 글`
   - `Enter your search term…` → `검색어를 입력하세요`
   - `Result(s) found`, `You May Also Enjoy`, `minute read`, `Tags`, `Share on`도 한국어로 바꾼다.
   - 스크린리더용 `Toggle search/menu` 라벨도 한국어로 바꾼다.
4. 홈의 `최근 글`과 `Latest Notes` 중복 제목을 하나로 합치고 첫 화면 안에 첫 글 카드 일부가 보이도록 상단 여백을 줄인다.
5. 글 상세 모바일 진입부를 압축한다.
   - 글 페이지에서는 작성자 프로필을 한 줄 형태로 축소한다.
   - 제목 크기를 약 `1.9rem–2.35rem` 범위로 조정하고 제목 위 공백을 줄인다.

### P2 — 읽기 경험과 재방문성 개선

6. 데스크톱 목차 글자 크기와 대비를 높이고 현재 읽는 섹션을 표시한다.
   - 긴 목차는 내부 스크롤을 허용하고 본문과 겹치지 않게 한다.
   - 모바일에서는 접을 수 있는 `목차 보기`를 고려한다.
7. 글 하단의 추천 글, 읽기 시간, 공유 영역을 한국어로 통일하고 다음 글이 없을 때 비활성 링크를 노출하지 않는다.
8. 검색 결과에 카테고리·날짜를 추가하고 일치한 단어를 강조해 결과 선택을 돕는다.

## 구현 대상

- `assets/css/main.scss`: 테마 버튼, 모바일 글 진입부, 목차, 홈 간격
- `_includes/masthead.html`: 테마 버튼 위치, 검색·메뉴 접근성 라벨
- 검색 스크립트 또는 커스텀 검색 include: `input` 이벤트, 한국어 상태 문구, 결과 메타정보
- `_data/ui-text.yml` 또는 사이트 전용 번역 데이터: 공통 UI 한국어화
- `_layouts/post.html`, `index.md`: 글 진입부 및 홈 섹션 구조

기존 `assets/css/main.scss`에는 아직 커밋되지 않은 사용자 변경이 있으므로 구현 전에 해당 변경을 보존한 상태에서 작업해야 한다.

## 완료 기준

- 390×844에서 테마 버튼이 카드나 본문을 가리지 않는다.
- `cache`, `LLM`, `캐싱` 검색이 키 입력·붙여넣기·자동완성에서 모두 갱신된다.
- 검색 빈 상태, 결과 수, 관련 글, 읽기 시간이 한국어로 표시된다.
- 키보드만으로 검색 열기·입력·결과 선택·닫기가 가능하다.
- 다크/라이트 테마, 1280px/390px, 200% 확대에서 가로 스크롤이나 콘텐츠 겹침이 없다.
- Lighthouse 또는 axe 자동 검사와 실제 키보드 순회에서 치명적 접근성 오류가 없다.

## 감사 한계

이번 점검은 현재 실행 화면의 시각 검사와 DOM 구조 확인을 기준으로 했다. 전체 스크린리더 순회, 색 대비 수치 측정, 200% 확대, Core Web Vitals, 다양한 실제 모바일 기기 검증은 아직 수행하지 않았으므로 WCAG 준수를 단정하지 않는다.
