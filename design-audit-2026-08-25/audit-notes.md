# FreeToken 글 화면 재검토

검토일: 2026-08-25

## 전체 판정

데스크톱 목차가 화면 오른쪽 밖으로 밀리던 문제는 해결됐다. 1200px, 1440px, 1920px에서 목차가 뷰포트 안에 들어오고 가로 overflow가 생기지 않는다. 모바일에서는 데스크톱 목차가 숨겨지고 접이식 목차가 정상 동작한다.

## 1. 데스크톱 글 화면

- 상태: 양호
- 증거: `01-freetoken-desktop-toc-fixed.jpg`
- 목차의 중복 수평 이동을 제거해 본문 오른쪽 열 안에 배치했다.
- 1440px 화면에서 목차 경계는 x=1121.6–1308.8px이며, 뷰포트 폭 1440px 안에 여유를 두고 들어온다.
- 본문과 목차가 겹치지 않고 가로 스크롤도 생기지 않는다.

## 2. 모바일 글 화면

- 상태: 양호
- 증거: `02-freetoken-mobile-toc-collapsed-final.jpg`, `03-freetoken-mobile-toc-expanded.jpg`
- 375px 화면에서 데스크톱 목차는 숨겨지고 `목차 보기`가 접힌 상태로 나타난다.
- 펼친 목차의 폭은 348px이며 375px 뷰포트 안에 들어온다.
- 접기/펼치기 동작과 목차 링크 구조를 확인했다.

## 접근성 확인 범위

- 목차에는 데스크톱 `목차`, 모바일 `모바일 목차` 내비게이션 레이블이 있다.
- 모바일 목차는 native `details`/`summary`를 사용해 키보드 기본 동작을 기대할 수 있다.
- 스크린샷만으로 색 대비 수치, 전체 키보드 포커스 순서, 스크린 리더 발화까지 판정하지는 않았다.
